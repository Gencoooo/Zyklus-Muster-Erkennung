Zyklus Challenge – PWA

Diese Version ist installierbar und funktioniert nach dem ersten Laden auch offline.

Wichtig:
Eine PWA muss über HTTPS gehostet werden. Direkt aus der Dateien-App kann iOS sie nicht als echte PWA installieren.

Einfachste Optionen:
1. Netlify Drop
   - Öffne https://app.netlify.com/drop
   - Ziehe den gesamten Ordner "Zyklus_Challenge_PWA" hinein
   - Öffne die erzeugte HTTPS-Adresse in Safari
2. GitHub Pages
   - Lade alle Dateien dieses Ordners in ein Repository
   - Aktiviere Pages für den Branch

Auf dem iPhone installieren:
1. HTTPS-Adresse in Safari öffnen
2. Teilen
3. "Zum Home-Bildschirm"
4. "Hinzufügen"

Die App:
- startet im Vollbild/Standalone-Modus
- hat ein eigenes App-Icon
- speichert alle Personen und Einträge lokal im Browser
- funktioniert nach dem ersten erfolgreichen Laden offline
- enthält Export/Import für Backups

Hinweis:
Wenn Browser-/Website-Daten gelöscht werden, können lokale App-Daten verloren gehen. Deshalb gelegentlich über "Mehr > Exportieren" sichern.
